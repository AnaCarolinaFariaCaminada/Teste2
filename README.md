# CadastroPaciente

Este é um repositório que contém o código de um formulário simples e intuitivo para o cadastro de pacientes. O projeto foi desenvolvido com foco na usabilidade, incluindo formatação automática de campos e validações de segurança.

## ✨ Funcionalidades

*   **Máscara de CPF:** Formatação em tempo real enquanto o usuário digita (ex: `000.000.000-00`).
*   **Validação de Campos:** Bloqueio de envio caso os campos obrigatórios estejam vazios.
*   **Interface Responsiva:** Design simples que se adapta a computadores e celulares.
